후원 메뉴판
설정 완전 가이드

후원 메뉴판은 "이 선물을 보내면 이걸 해드립니다"를 한눈에 보여주는 방송 화면 보드입니다. 시청자가 무엇을 후원할 수 있는지 고민하지 않게 만들어, 선물 전환율을 높이는 가장 직접적인 도구입니다. 이 가이드는 메뉴판 제작부터 화면 송출, 메뉴 구성 전략까지 전 과정을 다룹니다.

작성 2026년 5월 21일 수정 2026년 6월 12일 형식 영상 + 텍스트 난이도 입문

▶ 재생 버튼을 누르세요 · 전체화면 지원 · 아래 텍스트 가이드와 함께 보면 더 정확합니다

메뉴판이 왜 효과적인가

TikTok LIVE 시청자 대부분은 선물을 보내고 싶어도 "뭘 보내면 되는지"를 모릅니다. 채팅으로 물어보는 시청자는 소수이고, 대부분은 그냥 지나갑니다. 메뉴판은 이 진입 장벽을 없앱니다. "장미 10개 → 노래 신청", "사자 → 1시간 같이 게임"처럼 선물과 보상을 표로 보여주면, 시청자는 메뉴를 고르듯 후원할 수 있습니다.

식당에 메뉴판이 없으면 주문이 줄어드는 것과 같은 원리입니다. 실제로 먹방·노래·소통 방송에서 메뉴판은 거의 표준 장비처럼 쓰이고 있습니다.

단계별 설정 방법

  1. 메뉴판 열기 — Tikke 앱 사이드바에서 메뉴판 설정 메뉴로 이동합니다.
  2. 셀 구성 — 격자(그리드)의 각 셀에 선물 종류와 표시할 텍스트를 매핑합니다. 예를 들어 첫 셀에 "장미 ×10 — 노래 신청"을 넣는 식입니다. 행·열 수와 셀 크기, 간격은 방송 화면 비율에 맞게 조절할 수 있습니다.
  3. 꾸미기 — 색상, 폰트 크기, 굵기를 일괄 적용해 방송 컨셉에 맞는 톤으로 맞춥니다. 화면에서 또렷하게 읽히는 것이 최우선입니다.
  4. 화면에 송출 — 메뉴판 오버레이 URL을 복사해 TikTok LIVE Studio의 브라우저 소스로 추가합니다. 위치와 크기는 LIVE Studio에서 자유롭게 배치합니다.
  5. 백업 — 내보내기/불러오기 기능으로 메뉴판 구성을 JSON 파일로 저장해 둘 수 있습니다. PC를 바꾸거나 재설치해도 그대로 복원됩니다.

운영에 유용한 기능

  • 자동 동기화 — 메뉴판을 수정하면 클라우드에 자동 저장되고, 방송 화면 오버레이에도 실시간 반영됩니다. 방송 중에 메뉴를 바꿔도 LIVE Studio를 다시 만질 필요가 없습니다.
  • 셀 활성/비활성 — 품절된 메뉴처럼 지금 받지 않는 항목은 비활성 처리할 수 있습니다. 그레이스케일 옵션을 켜면 비활성 셀이 흑백으로 표시되어 시청자가 한눈에 구분합니다.
  • JSON 호환 — 내보낸 설정 파일은 다른 PC의 Tikke에서 그대로 불러올 수 있어, 서브 PC나 새 컴퓨터로 이사할 때 재작업이 없습니다.

메뉴 구성 전략 — 무엇을 올릴 것인가

  • 가격대 사다리 — 저가(부담 없는 진입), 중가(주력), 고가(이벤트성) 메뉴를 골고루 배치하세요. 전부 고가면 진입 장벽이 생기고, 전부 저가면 객단가가 낮아집니다.
  • 보상은 구체적으로 — "감사 인사"보다 "이름 불러주며 손하트"가 전환율이 높습니다. 시청자가 받을 장면을 상상할 수 있게 쓰세요.
  • 너무 많은 메뉴는 독 — 선택지가 많으면 오히려 결정을 미룹니다. 6~9개 내외가 읽기에도, 고르기에도 적당합니다.
  • 즉시 이행 가능한 것만 — 방송 중 바로 해줄 수 없는 보상(나중에 영상 제작 등)은 분쟁의 씨앗이 됩니다. 그 자리에서 이행 가능한 메뉴 위주로 구성하세요.
  • 주기적 리뉴얼 — 단골은 메뉴판을 이미 외우고 있습니다. 2~4주 주기로 한두 칸씩 바꾸면 "오늘은 뭐가 바뀌었나" 보는 재미가 생깁니다.

자주 묻는 질문

방송 화면에 메뉴판이 안 보여요

  • TikTok LIVE Studio 브라우저 소스에 오버레이 URL이 정확히 들어갔는지 확인하세요. URL을 다시 복사해 붙여넣는 것이 가장 빠릅니다.
  • 브라우저 소스의 크기가 0이거나 다른 소스에 가려져 있지 않은지 LIVE Studio 장면 구성을 확인하세요.

수정했는데 화면에 반영이 안 돼요

메뉴판 변경은 자동 동기화됩니다. 반영이 안 보이면 LIVE Studio에서 해당 브라우저 소스를 새로고침하거나, 잠시 후 다시 확인하세요. 인터넷 연결이 불안정하면 동기화가 지연될 수 있습니다.

글씨가 방송에서 잘 안 읽혀요

모바일 시청자 기준으로 생각해야 합니다. 폰트 크기를 키우고, 배경과 대비가 강한 색을 쓰고, 셀 하나에 들어가는 글자 수를 줄이세요. 긴 설명은 방송 멘트로 보충하는 편이 낫습니다.
