선물 사운드
등록 완전 가이드

TikTok LIVE에서 선물이 도착하는 순간 자동으로 사운드가 재생되면, 방송에 리듬이 생기고 후원자는 즉각적인 반응을 받습니다. 이 가이드는 사운드 파일 준비부터 선물 매핑, 재생 방식 선택, 운영 노하우, 문제 해결까지 전 과정을 다룹니다.

선물 사운드가 왜 필요한가

TikTok LIVE에서 선물은 방송인의 핵심 수익원이지만, 화면 속 작은 애니메이션만으로는 놓치기 쉽습니다. 게임을 하거나 노래를 부르는 중이라면 더욱 그렇습니다. 선물 사운드를 설정해 두면 어떤 선물이 왔는지 소리만으로 즉시 알 수 있고, 후원자 입장에서는 자신의 선물이 방송에 "울려 퍼지는" 경험을 하게 됩니다.

실제 운영에서 선물 사운드의 효과는 두 가지로 나타납니다. 첫째, 방송인이 선물을 놓치지 않고 바로 감사 인사를 할 수 있어 후원자 만족도가 올라갑니다. 둘째, 다른 시청자들도 "선물을 보내면 저런 반응이 나오는구나"를 학습하게 되어 후속 선물로 이어지는 경우가 많습니다.

시작 전 준비물

사운드 파일 형식

  • 지원 형식 — mp3, wav 파일을 사용할 수 있습니다. mp3는 용량이 작아 여러 개 등록할 때 유리하고, wav는 무손실이라 음질이 중요할 때 적합합니다.
  • 권장 길이 — 1~5초 내외가 적당합니다. 10초가 넘는 사운드는 연속 선물 시 소리가 계속 겹치거나 대기열이 밀려 방송 흐름을 해칠 수 있습니다.
  • 볼륨 통일 — 파일마다 녹음 볼륨이 다르면 어떤 선물은 작게, 어떤 선물은 갑자기 크게 들립니다. 등록 전에 비슷한 음량으로 맞춰두는 것이 좋습니다.

저작권 주의

방송에서 재생되는 사운드는 TikTok 커뮤니티 가이드라인과 저작권법의 적용을 받습니다. 유행하는 노래 후렴구를 그대로 잘라 쓰면 음악 저작권 침해로 방송 중단·계정 경고를 받을 수 있습니다. 효과음 전문 무료 라이브러리(저작권 표기 조건 확인)나 직접 녹음한 소리, 구매한 효과음을 사용하는 것이 안전합니다. Tikke 앱 내 사운드 탐색 기능에서 제공되는 효과음을 활용하는 것도 방법입니다.

단계별 등록 방법

  1. 사운드 파일 업로드 — Tikke 앱 사이드바에서 선물 사운드 메뉴로 이동한 뒤, + 파일 추가 버튼으로 준비한 mp3/wav 파일을 업로드합니다. 업로드된 파일은 목록에서 미리 들어볼 수 있습니다.
  2. 선물 매핑 규칙 만들기 — + 선물 추가를 눌러 어떤 선물에 어떤 사운드를 재생할지 규칙을 만듭니다. 예를 들어 "장미 → 딩동 효과음", "사자 → 팡파레"처럼 선물 종류별로 다른 사운드를 연결할 수 있습니다.
  3. 볼륨 조정 — 사운드별 재생 볼륨을 조절해 방송 음성과 균형을 맞춥니다. 마이크 소리를 덮지 않는 수준이 기준입니다.
  4. 라이브 연결 후 자동 재생 — TikTok LIVE 세션이 연결된 상태에서 매핑된 선물이 도착하면 사운드가 자동 재생됩니다. 별도 조작은 필요 없습니다.

재생 방식 상세 — 동시 재생과 대기열

선물이 한꺼번에 쏟아질 때 사운드를 어떻게 처리할지가 운영 품질을 가릅니다. Tikke는 두 가지 모드를 제공합니다.

  • 동시 재생 ON — 여러 선물의 사운드를 겹쳐서 동시에 재생합니다. 선물 러시 때 화려한 느낌을 주지만, 너무 많이 겹치면 소리가 뭉개집니다. 동시 재생 한도를 초과한 사운드는 자동으로 건너뜁니다.
  • 동시 재생 OFF — 사운드를 순서대로 하나씩 큐(대기열)에 넣어 재생합니다. 모든 선물 소리가 또렷하게 들리지만, 대량 선물 시 대기열이 길어질 수 있습니다. 대기열 한도를 초과하면 오래된 항목부터 정리됩니다.
  • 이모티콘 중복 방지 — 시청자들이 같은 이모티콘 선물을 연타하면 100ms 같은 짧은 시간 안에 동일 사운드가 수십 번 트리거될 수 있습니다. 중복 방지 옵션을 켜면 짧은 윈도우 내 연속 이모티콘은 첫 번째만 재생되어 소리 폭주를 막습니다.

운영 노하우 — 사운드를 후원 동기로 만들기

  • 가격대별 차등 — 저가 선물에는 가볍고 짧은 효과음, 고가 선물에는 길고 화려한 사운드를 배치하세요. 시청자가 "더 큰 선물 = 더 큰 반응"이라는 구조를 자연스럽게 인지하게 됩니다.
  • 시그니처 사운드 — 방송을 대표하는 고유 사운드를 하나 정해두면, 단골 시청자들 사이에서 밈처럼 자리 잡습니다. 다른 방송과 차별화되는 가장 저렴한 방법입니다.
  • 피로도 관리 — 모든 선물에 사운드를 달면 오히려 소음이 됩니다. 핵심 선물 5~10종에만 매핑하고 나머지는 조용히 지나가게 두는 편이 듣기 좋습니다.
  • 주기적 교체 — 같은 사운드를 몇 달씩 쓰면 신선함이 떨어집니다. 시즌 이벤트(할로윈, 크리스마스 등)에 맞춰 교체하면 방송에 변화를 줄 수 있습니다.

자주 묻는 질문

사운드가 재생되지 않아요

  • TikTok LIVE 세션이 Tikke에 연결되어 있는지 먼저 확인하세요. 연결 상태는 앱 상단 상태 표시에서 볼 수 있습니다.
  • 해당 선물에 매핑 규칙이 만들어져 있는지, 규칙이 활성화 상태인지 확인하세요.
  • Windows 출력 장치가 바뀌었을 수 있습니다. 시스템 기본 재생 장치와 앱 볼륨 믹서를 확인하세요.

방송 송출에는 소리가 안 들어가요

선물 사운드는 방송인 PC에서 재생됩니다. 시청자에게도 들리게 하려면 방송 송출 프로그램이 PC 소리(데스크톱 오디오)를 캡처하도록 설정되어 있어야 합니다. 마이크만 송출하는 설정이라면 사운드가 시청자에게 전달되지 않습니다.

특정 선물만 소리가 너무 커요

파일 자체의 녹음 볼륨 차이입니다. 해당 사운드의 개별 볼륨을 낮추거나, 오디오 편집 도구로 파일 음량을 정규화한 뒤 다시 업로드하세요.
