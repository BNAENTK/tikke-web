후원을 한곳에서
모아 집계하기

Yukke는 여러 플랫폼에 흩어진 후원을 한 화면으로 모아 점수로 환산하고, 순위·게이지·알림 오버레이로 내보내는 앱입니다. 엑셀방송처럼 후원 집계가 방송의 중심인 환경을 위해 만들었습니다.

연결 가능 6개 플랫폼 로그인 불필요 대상 OS Windows

Tikke를 쓰고 계셨다면 먼저 알아두실 점이 있습니다. Yukke는 Tikke의 다른 모드가 아니라 완전히 별개의 앱입니다. 설정도 공유하지 않고, 두 앱을 동시에 켜 두어도 서로 간섭하지 않습니다.

1. Yukke가 하는 일

본체는 집계입니다. 여러 플랫폼에서 들어온 후원을 모아 → 점수로 환산하고 → 순위와 게이지로 보여주고 → 기록으로 남깁니다. 통합 채팅과 위젯은 그 위에 얹힌 보조 기능입니다.

사이드바 구성은 다음과 같습니다.

  • 대시보드 — 연결 상태와 오버레이 주소
  • 채팅창 — 채팅창 · 시청자수 · 공지 · 타이머
  • 후원 알림 — 후원 관리 · 후원 알림 · 룰렛 후원 · 시그니처 사운드 · 시그니처 관리 · 큰손 입장
  • 후원 자막 · 목표치그래프
  • 위젯 — 빙고판 · 전광판 · 투표 · 이모티콘 리액션 · 엔딩 크레딧
  • 자막/스코어 · 배너
  • 계좌 입금 · 환산 설정

2. 설치 — 다운로드 암호가 필요합니다

Yukke는 공개 배포가 아닙니다. 다운로드 페이지에서 Access Code를 입력해야 설치 파일 주소가 열립니다. 코드는 배포자에게 받으세요. 틀린 코드를 여러 번 넣으면 잠시 시도가 막힙니다.

코드를 통과하면 Yukke-Setup.exe를 받습니다. 현재 Windows 설치 파일만 제공합니다.

3. 첫 실행 — 약관 동의

처음 실행하면 이용약관·개인정보처리방침 동의 화면이 뜹니다. Yukke에는 로그인이 없습니다. 그래서 여기서 거부를 누르면 로그아웃이 아니라 앱이 종료됩니다.

i

계정도, API 키도, 구글 로그인도 필요 없습니다. 방송 플랫폼에 로그인하거나 쿠키를 붙여넣는 절차가 없습니다. 아래 6개 플랫폼 전부 공개 경로로만 읽습니다.

4. 방송 연결 — 플랫폼별로 넣는 값이 다릅니다

대시보드 맨 위에 YouTube · TikTok · SOOP · Twitch · CHZZK · 투네이션 카드가 한 줄로 놓여 있습니다. 쓰려는 카드의 연결을 누르고 아래 값을 넣으세요. 연결된 카드는 색이 채워져 한눈에 구분됩니다. 여러 플랫폼을 동시에 연결할 수 있고, 그게 이 앱의 핵심입니다.

공통 조건은 방송이 이미 켜져 있어야 한다는 것입니다. 방송 시작 전에 연결하면 붙지 않습니다.

  • 유튜브 — @채널핸들 또는 라이브 방송 주소
  • 틱톡 — 아이디만 (@ 빼고)
  • 숲(SOOP) — BJ 아이디, 또는 play.sooplive.co.kr/… 주소
  • 트위치 — 채널명 (예: zackrawrr)
  • 치지직 — 채널 주소, 또는 32자 채널 id
  • 투네이션 — 알림창 주소 (toon.at/widget/alertbox/…) — 채널명이 아니라 알림창 위젯 주소입니다

한 번 연결해 두면 설정에 남아, 다음부터는 앱을 켜기만 해도 자동으로 다시 붙습니다.

!

틱톡만 자동 재시도가 없습니다. 틱톡은 연결에 외부 서명 서버를 거치는데, 자동으로 계속 재시도하면 요청 한도에 걸려 오히려 더 못 붙습니다. 그래서 실패 시 직접 다시 눌러야 합니다. 나머지 플랫폼은 끊기면 알아서 다시 붙습니다.

연결이 안 될 때는 방송을 시작하고 1분쯤 기다린 뒤 다시 시도하세요. 플랫폼이 방송 정보를 공개하기까지 시간이 걸립니다.

5. 오버레이 주소 넣기

주소를 얻는 곳은 두 군데입니다.

  • 대시보드 — 아래로 내리면 위젯 카드가 미리보기 그림과 함께 쭉 나옵니다. 각 카드의 URL 복사를 누르면 바로 복사됩니다. 어떤 오버레이인지 그림으로 확인하고 고를 때 편합니다.
  • 각 화면 위쪽 — 그 화면 전용 주소 줄이 있습니다. URL 복사 · 열기 · QR 버튼이 함께 있어, QR로 휴대폰에서 바로 열어 확인할 수 있습니다.

두 곳 모두 이 PC와 어디서나를 전환할 수 있습니다.

  • 이 PC — http://localhost:18191/overlay/… · 방송 프로그램이 Yukke와 같은 컴퓨터에 있을 때
  • 어디서나 — 클라우드 주소 · 다른 컴퓨터나 휴대폰에서 열어야 할 때

Tikke와 포트가 다릅니다(Tikke는 18181). 두 앱을 함께 켜도 충돌하지 않도록 나눠 둔 것입니다.

!

클라우드 주소의 방 키는 바꾸지 마세요. 방 키는 처음 한 번 만들어져 고정됩니다. 이 값이 바뀌면 방송 프로그램에 넣어 둔 오버레이 주소가 전부 한꺼번에 끊깁니다.

방송 프로그램 쪽에서는 장면을 전환할 때 브라우저 소스가 새로고침되지 않도록 설정해 두세요. 새로고침될 때마다 화면에 쌓인 상태가 초기화됩니다.

6. 환산 설정 — 두 가지 규칙을 구분하세요

여기가 가장 많이 헷갈리는 부분입니다. Yukke에는 성격이 다른 두 가지 숫자 규칙이 있습니다.

① 점수 환산 — 순위·게이지·목표치에 쓰입니다

플랫폼마다 화폐가 달라서(별풍선, 다이아, 치즈, 비트…) 공통 점수로 바꿉니다. 사이드바 환산 설정에서 조정합니다. 기본값은 다음과 같습니다.

  • 유튜브 슈퍼챗 · 치지직 치즈 · 계좌 입금 — 1원 = 1점
  • 투네이션 — 100원 = 90점
  • 페이팔 — 1달러 = 1000점
  • 숲 별풍선 — 1개 = 100점
  • 트위치 비트 — 1개 = 14점
  • 틱톡 다이아 — 1개 = 7점

② 후원 사운드 규칙 — 환산하지 않습니다

“얼마 이상이면 이 소리를 재생” 규칙은 점수가 아니라 실제 넣은 수를 그대로 봅니다. 별풍선이면 별풍선 개수, 틱톡이면 다이아 수, 계좌면 원 단위 금액입니다. 점수 기준으로 잡으면 원하는 때 안 울립니다.

규칙이 여러 개 걸리면 기준선이 가장 높은 하나만 울리고, 여러 소리가 겹치지 않게 한 번에 하나씩 차례로 재생됩니다. 틱톡 선물은 이름이 아니라 선물 번호로 지정합니다.

7. 계좌 입금·페이팔 받기

은행은 후원 연동을 제공하지 않습니다. 그래서 Yukke는 휴대폰의 입금 알림을 읽어 보내는 방식을 씁니다.

  1. 사이드바 계좌 입금 화면을 엽니다.
  2. 화면의 QR을 휴대폰으로 찍어 설정 페이지를 엽니다. (주소가 길어 PC에서 복사해 옮기기 어렵기 때문입니다.)
  3. 휴대폰에 자동화 앱(MacroDroid 또는 Tasker)을 설치하고, 안내대로 입금 알림을 전달하도록 설정합니다.
  4. 화면의 테스트 입금 버튼으로 잘 들어오는지 확인합니다.
!

수신 주소는 공유하지 마세요. 이 주소를 아는 사람은 누구나 가짜 입금을 밀어 넣을 수 있습니다. 방송 화면에 노출되지 않도록 주의하세요.

8. 헷갈리기 쉬운 것들

  • 탭은 다른 화면이 아닙니다. 화면 위쪽의 기본 설정 · 상세 설정 · 폰트·배경 같은 탭을 누르면 페이지가 바뀌는 게 아니라, 같은 화면 안의 그 위치로 스크롤됩니다. 설정은 모두 한 화면에 세로로 쌓여 있습니다.
  • 설정을 바꿨으면 설정 저장을 누르세요. 화면 오른쪽 위에 저장·초기화 버튼이 있습니다.
  • 전광판·시청자수·공지·타이머는 한 오버레이를 함께 씁니다. 각각 설정은 따로지만 같은 뿌리라, 넷을 동시에 다른 용도로 띄우려면 주소를 각각 넣어야 합니다.
  • 시청자수 위젯은 아직 실제 시청자 수를 받아오지 않습니다. 화면은 있지만 숫자가 채워지지 않습니다.
  • 유튜브는 연결 전에 쌓여 있던 채팅을 흘려보내지 않습니다. 같은 후원을 두 번 집계하지 않기 위한 동작입니다. 연결한 시점부터 들어오는 것만 잡힙니다.
i

이 문서에 없는 화면별 세부 설정(테마 고르기, 등장 효과 등)은 앱 안 각 화면 위쪽의 한 줄 설명에 정리돼 있습니다. 먼저 그쪽을 보시고, 그래도 막히면 문의로 알려주세요.
