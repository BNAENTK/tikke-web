01 / INSTALL

설치 및 최초 실행

Tikke는 Windows와 macOS 모두 지원하는 데스크톱 전용 애플리케이션입니다. 별도 회원가입 없이 다운로드 후 즉시 실행할 수 있습니다.

다운로드

1
설치 파일 다운로드
tikke.kr 홈페이지에서 운영체제에 맞는 설치 파일을 내려받습니다. Windows는 .exe, macOS는 .dmg 형식입니다.
2
설치 실행 (Windows)
다운로드한 Tikke-Setup.exe를 실행합니다. "Windows의 PC 보호" 경고가 나타나면 추가 정보 → 실행을 클릭하세요. Tikke는 서명된 앱이지만 Microsoft SmartScreen이 새 앱에 경고를 표시하는 경우가 있습니다.
3
설치 실행 (macOS)
Tikke-Setup.dmg를 열고 Tikke 아이콘을 Applications 폴더로 드래그합니다. 처음 실행 시 "알 수 없는 개발자" 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 선택하세요.
4
최초 실행
설치 후 Tikke를 실행하면 로딩 화면과 함께 메인 대시보드가 열립니다. 최초 실행 시 자동으로 최신 버전 확인 및 업데이트가 진행될 수 있습니다.
💡 Tikke는 자동 업데이트를 지원합니다. 새 버전이 나오면 앱 실행 시 알림이 표시되며, 클릭 한 번으로 업데이트할 수 있습니다.
02 / CONNECT

TikTok LIVE 연결

Tikke는 TikTok LIVE의 공개 데이터 스트림을 직접 수신합니다. 복잡한 API 설정 없이 TikTok 사용자 아이디(닉네임)만 입력하면 연결됩니다.

연결 방법

1
사용자 아이디 입력
상단 입력창에 TikTok 사용자 아이디를 @ 없이 입력합니다. 예: tikke_official
2
LIVE 시작 후 연결
TikTok LIVE 방송을 먼저 시작한 뒤 Tikke에서 연결 버튼을 클릭합니다. 방송 전에는 연결되지 않습니다.
3
연결 상태 확인
상단 상태바에 연결됨 · LIVE가 표시되면 모든 모듈이 실시간 데이터 수신을 시작합니다.
⚠ Tikke는 TikTok 공식 API가 아닌 공개 데이터를 수신합니다. TikTok 정책 변경에 따라 일시적으로 연결이 불안정해질 수 있습니다. 안정적인 방송을 위해 항상 최신 버전을 유지하세요.
03 / DASHBOARD

대시보드 — 라이브 관제

Tikke의 메인 대시보드는 방송 중 발생하는 모든 데이터를 한 화면에서 보여줍니다. 흥미도 점수, 시청자 수, 채팅·선물 빈도를 실시간으로 모니터링하고 방송의 흐름을 읽을 수 있습니다.

흥미도 점수 (Engagement Score)

흥미도 점수는 0~100 사이의 숫자로, 채팅 빈도·다이아 선물·시청자 입퇴장 등 여러 지표를 종합해 방송의 활성도를 실시간으로 계산합니다. 점수가 떨어지기 시작하면 이벤트나 게임을 진행해 시청자의 참여를 유도하는 신호로 활용하세요.

  • 80 이상 — 매우 활발. 선물·채팅이 쏟아지는 피크 타임.
  • 50~79 — 정상 방송. 꾸준히 유지하는 것이 목표.
  • 49 이하 — 활동 저하 신호. 인터랙션을 늘려야 할 때.

실시간 지표 패널

대시보드 상단에는 다음 지표가 초 단위로 갱신됩니다.

  • 시청자 수 — 현재 방송을 보고 있는 총 인원
  • 채팅 속도 — 분당 채팅 메시지 수 (msg/min)
  • 선물 속도 — 분당 다이아 선물 수 (diamonds/min)
  • 팔로우 — 방송 중 새로 팔로우한 수
  • 공유 — 방송 링크 공유 횟수

흥미도 그래프

대시보드 하단의 실시간 선형 그래프는 지난 수 분간의 흥미도 추이를 시각화합니다. 그래프가 급격히 하락하기 전에 방송 콘텐츠를 전환하거나 선물 이벤트를 진행하는 데 활용합니다.

💡 흥미도가 60 아래로 내려가면 시청자에게 직접 질문하거나, 선물 목표를 공표하거나, 미니게임을 시작해 보세요. 채팅 참여도가 올라가면서 점수가 빠르게 회복됩니다.
04 / CHAT · TRANSLATE · AI

채팅 · 번역 · AI 자동응답

Tikke의 채팅 모듈은 단순한 채팅창을 넘어, 다국어 번역과 AI 기반 자동응답 기능을 통해 글로벌 시청자와의 소통을 자동화합니다.

실시간 채팅 번역

방송 중 들어오는 채팅 메시지를 38개 언어에서 한국어(또는 원하는 언어)로 자동 번역합니다. 외국 시청자가 영어, 일본어, 중국어 등으로 보낸 채팅을 즉시 이해할 수 있습니다.

1
번역 언어 설정
채팅 패널 상단에서 번역 대상 언어와 출력 언어를 선택합니다. "자동 감지 → 한국어" 설정을 권장합니다.
2
번역 필터
한국어 채팅은 번역 없이 그대로 표시하고, 외국어 채팅만 번역해 보여주는 필터 옵션을 활성화합니다.

AI 자동응답

반복적인 질문(예: "어떤 게임 해요?", "나이가 어떻게 되세요?")에 자동으로 답변을 달아주는 기능입니다. 자주 받는 질문과 답변을 미리 등록해 두면, 매칭되는 채팅이 들어올 때 자동으로 응답하거나 스트리머에게 알림을 보냅니다.

채팅 모더레이션

특정 키워드가 포함된 채팅을 자동으로 숨기거나 강조 표시할 수 있습니다. 도배·욕설·스팸 채팅을 필터링하고, VIP 시청자나 선물 발송자의 채팅을 별도로 표시하는 데 활용합니다.

05 / ON-SCREEN

화면 송출 — 오버레이 설정

Tikke의 오버레이 시스템은 TikTok LIVE Studio의 브라우저 소스와 연동해 방송 화면에 실시간 정보를 표시합니다. 시청자에게 보이는 화면에 선물 알림, 채팅 창, 리그 조각컷 등 다양한 요소를 띄울 수 있습니다.

TikTok LIVE Studio 연결

1
오버레이 URL 복사
Tikke 오버레이 패널에서 원하는 오버레이 항목의 URL을 복사합니다.
2
TikTok LIVE Studio에 추가
TikTok LIVE Studio → 레이아웃 편집 → + 추가 → 웹 URL을 선택하고 복사한 URL을 붙여넣습니다.
3
크기 및 위치 조정
추가된 브라우저 소스를 드래그해 화면에서 원하는 위치에 배치하고 크기를 조절합니다.

제공 오버레이 종류

OVERLAY · 01

선물 알림

다이아 선물이 들어올 때 화면에 팝업으로 알림을 표시합니다. 선물 종류와 발송자 이름이 애니메이션과 함께 나타납니다.

OVERLAY · 02

채팅 창

실시간 채팅을 방송 화면에 오버레이로 표시합니다. 번역된 채팅도 함께 표시할 수 있습니다.

OVERLAY · 03

Top 후원자

방송 중 가장 많은 선물을 보낸 상위 시청자 목록을 실시간으로 표시합니다.

OVERLAY · 04

리그 진행도

현재 리그 조각컷 대비 나의 위치를 게이지 바 형태로 방송 화면에 표시합니다.

OVERLAY · 05

흥미도 미터

실시간 흥미도 점수를 시각화한 미터를 방송 화면에 표시합니다.

ℹ 오버레이는 20종 이상 제공되며, 테마 색상 및 애니메이션 스타일을 커스터마이즈할 수 있습니다. 일부 오버레이는 Tikke가 TikTok LIVE에 연결된 상태에서만 데이터가 갱신됩니다.
06 / GIFTS · SOUND · TTS

선물 · 사운드 · TTS

시청자의 선물(다이아)에 소리와 시각 효과로 반응해 방송 분위기를 끌어올립니다. TTS(Text-to-Speech) 기능으로 채팅 메시지를 음성으로 읽어줄 수도 있습니다.

선물 사운드 알림

선물 종류별로 다른 효과음을 설정할 수 있습니다. 예를 들어 장미 선물에는 짧은 멜로디, 유니버스 선물에는 웅장한 효과음을 배정하면 방송의 현장감이 높아집니다.

  • 선물 패널에서 각 선물 아이템을 클릭해 사운드를 설정합니다.
  • 내 PC에 저장된 음원 파일(.mp3, .wav)을 불러오거나 기본 제공 사운드 팩을 사용합니다.
  • 볼륨 및 재생 길이를 개별 조정할 수 있습니다.

TTS (Text-to-Speech)

채팅 메시지를 자동으로 음성으로 읽어주는 기능입니다. 스트리머가 직접 채팅을 읽지 않아도 시청자의 메시지가 방송에서 소리로 전달됩니다. 특히 다중 채팅이 쏟아질 때 유용합니다.

  • TTS 대상 — 전체 채팅, VIP만, 선물 발송자만 등 조건 설정 가능
  • 언어 및 목소리 — 한국어·영어·일본어 등 다국어 TTS 지원
  • 속도·피치 — 읽기 속도와 음정을 조절해 원하는 느낌으로 설정
  • 필터 — 특정 키워드가 포함된 채팅은 TTS에서 제외 가능
💡 TTS는 방송 중 소리가 너무 많이 겹치면 오히려 집중을 방해합니다. 선물 발송자 채팅만 TTS로 읽고, 일반 채팅은 시각 오버레이로만 표시하는 설정을 권장합니다.
07 / LEAGUE CUTOFFS

리그 조각컷

TikTok LIVE 리그는 방송 중 획득한 다이아 선물 합계로 랭킹이 결정됩니다. Tikke의 리그 조각컷 기능은 A·B·C·D 리그의 상위 1%, 10%, 20% 컷오프를 실시간으로 추적합니다.

조각컷 확인 방법

Tikke 좌측 패널의 리그 조각컷 탭을 클릭하면 현재 시즌의 리그별 컷오프가 표시됩니다. 데이터는 5분마다 자동으로 갱신됩니다.

  • A 리그 — TikTok LIVE 최상위 리그. 상위 1%/10%/20% 컷오프 표시
  • B · C · D 리그 — 각 리그별 조각컷 목표 확인
  • 나의 현재 점수 — 이번 방송에서 받은 다이아 합계와 컷오프 대비 달성률

웹에서도 확인

앱 없이도 tikke.kr/cutoffs에서 최신 리그 조각컷을 확인할 수 있습니다.

ℹ 리그 조각컷 데이터는 TikTok 공개 데이터를 기반으로 집계됩니다. 실제 공식 TikTok 집계 기준과 차이가 있을 수 있으며, 참고용으로만 활용하세요.
08 / REGULARS · INTEGRATION

단골 관리 · 외부 연동

방송을 꾸준히 찾아주는 단골 시청자를 특별 관리하고, 다른 스트리밍 도구와 Tikke를 연결해 워크플로우를 확장할 수 있습니다.

단골 시청자 관리

방송에서 자주 채팅하거나 선물을 보내는 시청자를 자동으로 단골 목록에 추가합니다. 단골 시청자가 방송에 입장하면 별도 알림이 뜨고, 채팅창에 특별 뱃지가 표시됩니다.

  • 단골 지정 조건 (방문 횟수, 선물 총액 등)을 직접 설정
  • 단골 채팅에 배지·색상으로 시각 강조
  • 단골 입장 시 커스텀 알림 사운드 재생

외부 도구 연동

Tikke는 스트림덱(Stream Deck)과 같은 외부 컨트롤러와 연동이 가능합니다. 자주 사용하는 모듈 전환, 오버레이 표시/숨김, TTS 켜기/끄기 등의 동작을 스트림덱 버튼 하나로 실행할 수 있습니다.

09 / FAQ

자주 묻는 질문

Tikke는 무료인가요?
Tikke의 기본 기능은 무료로 제공됩니다. 채팅 수신, 실시간 번역, 기본 오버레이 등 핵심 기능을 무료로 사용할 수 있습니다. 일부 고급 기능(고급 AI 응답, 프리미엄 오버레이 팩 등)은 유료 플랜을 통해 제공될 수 있습니다.
TikTok 계정 로그인이 필요한가요?
아니요. Tikke는 TikTok 계정 로그인이 필요하지 않습니다. 방송 중인 TikTok 사용자 아이디(닉네임)만 입력하면 공개 데이터를 수신할 수 있습니다.
연결이 자꾸 끊기거나 데이터가 수신되지 않아요.
TikTok LIVE가 실제로 방송 중인지 먼저 확인하세요. 연결이 불안정한 경우 Tikke를 최신 버전으로 업데이트하거나, Tikke를 재시작한 후 다시 연결을 시도하세요. 네트워크 방화벽이나 VPN이 연결에 영향을 줄 수 있습니다.
번역이 지원되는 언어는 어떤 것들이 있나요?
영어, 일본어, 중국어(간체·번체), 스페인어, 포르투갈어, 아랍어 등 38개 언어를 지원합니다. 자동 감지 기능으로 언어를 직접 지정하지 않아도 됩니다.
오버레이가 TikTok LIVE Studio에서 보이지 않아요.
TikTok LIVE Studio에 추가한 브라우저 소스 URL이 정확한지 확인하세요. 브라우저 소스를 선택한 상태에서 새로고침을 클릭하거나, 소스를 삭제 후 재추가해 보세요. Tikke가 TikTok LIVE에 연결된 상태여야 오버레이에 데이터가 표시됩니다.
Mac에서 설치가 안 돼요. "손상된 파일" 오류가 납니다.
터미널을 열고 다음 명령어를 실행하세요: sudo xattr -rd com.apple.quarantine /Applications/Tikke.app. macOS의 게이트키퍼(Gatekeeper) 격리 속성을 제거하는 명령어입니다. 이후 정상적으로 실행됩니다.
